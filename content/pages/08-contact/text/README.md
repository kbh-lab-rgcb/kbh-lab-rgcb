# Text sections

**Each file here becomes one section on the page**, in filename order.

Create a file, name it `06-my-new-section.txt`, and write:

```text
title: My new section

The first line after the blank line starts the text. Leave a blank line
between paragraphs.

You can use **bold**, *italic*, [links](https://example.com) and bullet lists:

- first point
- second point
```

The `title:` line is the section heading. Everything after the blank line is the
body.

To remove a section, delete its file. To reorder, change the number at the front
of the filename.
