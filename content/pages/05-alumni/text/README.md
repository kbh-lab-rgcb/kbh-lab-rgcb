# Alumni

**One file per person who has left the lab.**

```text
name: Yadu Vijayan
role: PhD
year: 2024
thesis: Elucidation of the role of acid ceramidase in inflammation-driven colorectal cancer
now: Post-doctoral fellow, Virginia Commonwealth University, Richmond, VA, USA
```

`thesis:` and `now:` are what make this page useful — they are what visitors
come here to read. Everything is optional except `name:`.

Profile links (`orcid:`, `scholar:`, `linkedin:` and so on) work exactly as they
do on the team page, and appear only if you add them.

An alumnus can have a page of their own too: add `profile: yes` and write their
thesis work, positions and awards under `## Headings` in the same file. See
[`../../04-team/text/README.md`](../../04-team/text/README.md) — it works the
same way here.

Most recent first: use `01-` for the newest graduate.

A photo is optional. If you have one, put it in [`../photos/`](../photos) with
the same filename.
