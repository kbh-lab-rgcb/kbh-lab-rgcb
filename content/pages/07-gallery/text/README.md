# Gallery captions

**Optional.** Only add a file here if you want a caption on a particular photo
that sits loose in [`../photos/`](../photos).

Name it after the photo:

```text
photos/07-lab-retreat-2025.jpg
text/07-lab-retreat-2025.txt
```

and write the caption inside:

```text
caption: Lab retreat, Munnar, December 2025
```

Or just type the caption on its own with no `caption:` line — both work.

**Photos inside an album folder are captioned in that folder**, next to the
photo, rather than here — that way an album is one self-contained folder you can
move around. See [`../photos/README.md`](../photos/README.md).

Photos with no caption file show no caption, which is completely fine.
