# Figures

**A figure here is paired with the text section of the same name.**

```text
text/01-overview.txt
figures/01-overview.png                    <- shown beside that section
```

The names must match apart from the file extension. The number prefix must match
too.

The picture sits beside the opening of the section, with the writing running on
beneath it. If no figure matches, the section is simply full width. Nothing
breaks.

Add a caption by putting a `caption:` line in the text file:

```text
title: Overview
caption: The programme's research themes.
```

Pictures for the **Research stories** page go in
`content/pages/03-stories/figures/` instead.

Accepted: `.jpg` `.jpeg` `.png` `.webp` `.svg` `.gif`
