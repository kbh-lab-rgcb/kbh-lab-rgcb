# Figures

**A figure here is paired with the text section of the same name.**

```text
text/03-tumour-microenvironment.txt
figures/03-tumour-microenvironment.png     <- shown beside that section
```

The names must match apart from the file extension. The number prefix must match
too.

If no figure matches, the section is simply full width. Nothing breaks.

Add a caption by putting a `caption:` line in the text file:

```text
title: The tumour microenvironment
caption: S1PR1/STAT3 signalling in pancreatic stroma.
```

Accepted: `.jpg` `.jpeg` `.png` `.webp` `.svg` `.gif`
