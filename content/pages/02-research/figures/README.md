# Figures

**A figure here is paired with the text section or research story of the same
name.**

```text
text/01-overview.txt
figures/01-overview.png                    <- shown beside that section

stories/04-pancreatic-stroma.txt
figures/04-pancreatic-stroma.jpg           <- shown beside that story
```

The names must match apart from the file extension. The number prefix must match
too.

If no figure matches, the section or story is simply full width. Nothing breaks.

Add a caption by putting a `caption:` line in the text file:

```text
title: Breaking the stromal barrier to pancreatic cancer treatment
caption: Collagen laid down between the acini, in blue.
```

Accepted: `.jpg` `.jpeg` `.png` `.webp` `.svg` `.gif`
