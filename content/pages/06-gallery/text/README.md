# Gallery captions

**Optional.** Only add a file here if you want a caption on a particular photo.

Name it after the photo in [`../photos/`](../photos):

```text
photos/07-lab-retreat-2025.jpg
text/07-lab-retreat-2025.txt
```

and write the caption inside:

```text
caption: Lab retreat, Munnar, December 2025
```

Or just type the caption on its own with no `caption:` line — both work.

Photos with no file here show no caption, which is completely fine.
