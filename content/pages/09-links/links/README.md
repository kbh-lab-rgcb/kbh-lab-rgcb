# Outgoing links

**One file per link.** These point at the RGCB institute site and anywhere else
worth sending visitors.

```text
title: Research services and consultancy
url: https://rgcb.res.in/research-services
description: Analytical, genomic and diagnostic services offered by the institute.
featured: yes
```

- `title:` and `url:` are required. A file with no `url:` is skipped.
- `description:` is optional but makes the card much more useful.
- `featured: yes` **also shows the link on the front page.** Leave the line out
  to have it appear only here.

Order is by the number at the front of the filename.

To remove a link, delete its file.
