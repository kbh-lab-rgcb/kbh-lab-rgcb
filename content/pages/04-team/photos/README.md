# Team photos

**One photo per person.** Name it after the person, and give the matching text
file in [`../text/`](../text) the same name.

```text
photos/04-anna-t-varghese.jpg
text/04-anna-t-varghese.txt
```

Accepted: `.jpg` `.jpeg` `.png` `.webp` `.svg`

Photos are resized automatically, so upload the original — no need to shrink it
first. A portrait-shaped photo (taller than wide) looks best; faces are shown
centred.

## If you only have one half

That is fine, and deliberately so:

- **Photo but no text file** → the person still appears, with their name taken
  from the filename.
- **Text file but no photo** → the person still appears, with their initials in
  a coloured circle.

Neither breaks the website. Add the other half whenever you have it.
